# SkillHub — Academic Project

A full-stack project for a skill and gig-oriented platform, based on the repository's client/server structure.

## ✨ Project Areas
- **Skill and gig discovery:** repository code includes gig-search functionality
- **Freelancer workflows:** client components include gig-creation UI
- **Backend services:** a server-side application with repository/data-access code
- **Database integration:** SQL queries and a MySQL data-access layer are present in the source

## 🛠️ Technology
- React / JSX frontend components
- C# / .NET server-side code
- MySQL database integration

Check the solution and package/configuration files for exact versions and prerequisites.

## 🚀 Getting Started
1. Clone the repository:
   `git clone https://github.com/Muhammad-Yasir-Asad/DBS25F037.git`
2. Review the client and server folders.
3. Install the frontend dependencies using the package manifest in the client directory.
4. Open the server solution in a compatible .NET IDE/SDK and restore its dependencies.
5. Configure the MySQL connection and application settings locally; do not commit credentials.
6. Run the client and server using the scripts and launch settings supplied by the project.

## 🔐 Security
Use environment-specific configuration, parameterized queries, and sanitized test data. Keep database credentials out of commits.
